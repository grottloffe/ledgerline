# {{PROJECT_NAME}} — Follow-ups

Deferred work: shortcuts taken on purpose, hardening postponed, tests not
written yet, TODOs left in code. This is the honest debt register.

Every open follow-up needs a **trigger** — the observable condition that makes
it urgent. "Before launch", "when a second tenant signs up", "when this table
passes 100k rows" are triggers. "Later" and "when we have time" are not: if you
cannot name a trigger, drop the item instead of pretending it is tracked.

Status: `open` · `closed` · `dropped`
Size: `S` (< 1h) · `M` (a session) · `L` (needs its own feature row)
